# Pizza Sales Analysis | Power BI Project

## Project Overview

This project focuses on analyzing pizza sales data using Microsoft Power BI to evaluate sales performance, identify customer purchasing patterns, and explore trends across different pizza categories and sizes.

The analysis is based on **48,620 sales records** from 2015 and aims to transform transactional data into meaningful business insights through data modeling, KPI analysis, and interactive reporting.

## Tools & Technologies

- **Microsoft Power BI** – Sales analysis and interactive reporting
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – KPI calculations and analytical measures
- **Data Modeling** – Organizing sales data and date-related information
- **Data Visualization** – Charts, tables, and analytical reports

## Key Performance Indicators (KPIs)

The project focuses on the following sales performance metrics:

- **Total Revenue:** Total sales revenue generated from pizza orders.
- **Total Orders:** Number of unique customer orders.
- **Total Pizzas Sold:** Total quantity of pizzas sold.
- **Average Order Value:** Average revenue generated per order.
- **Average Pizzas per Order:** Average number of pizzas purchased per order.

## Data Analysis

The analysis focuses on:

- **Sales Trends:** Examining sales performance across different dates and time periods.
- **Pizza Category Analysis:** Comparing sales across Classic, Supreme, Chicken, and Veggie categories.
- **Pizza Size Analysis:** Evaluating sales distribution across different pizza sizes.
- **Product Performance:** Identifying best-selling and least-selling pizza varieties.
- **Revenue Analysis:** Comparing revenue contributions from different pizza products and categories.
- **Order Patterns:** Analyzing customer ordering behavior and sales volumes.

## Dashboard Features

The Power BI project is structured around sales data and a calendar table to support time-based analysis.

The dataset enables visualizations and reporting such as:

- Sales revenue and order volume monitoring.
- Sales trends by date and time period.
- Pizza category and size comparisons.
- Product-level sales performance analysis.
- Interactive filtering and time-based analysis.

## Dataset

The project uses the **Pizza Sales Dataset**, containing 48,620 transaction-level records from 2015.

The dataset includes information about order IDs, order dates, pizza names, quantities, unit prices, total prices, pizza sizes, categories, and ingredients.

**Dataset Source:** [Pizza Sales Dataset – Hugging Face](https://huggingface.co/datasets/Bizwhiznetwork/pizza_sales)

## Project Objective

The main objective of this project is to demonstrate how Microsoft Power BI can be used to analyze retail sales data, monitor sales performance, and identify patterns in product demand.

The project emphasizes practical applications of **data analysis, sales reporting, KPI monitoring, data visualization, and business intelligence** to support data-driven decision-making.
